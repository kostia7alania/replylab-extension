Style test выявил два дефекта: копирование заглушек из JSON-примера и смешение биографии собеседника с фактами владельца. Исправлены инструкция, role filtering и минимизация контекста. Повторный результат включал English-ограничение и переменные `{accountName}`/`{accountBio}`. AI-черновик всё равно требует просмотра перед сохранением.

Unit tests проверяют приватные file modes, nonce/JWKS/PKCE, refresh/sign-out race, SSE completion, archived-message ordering, tombstones, same-ID identity conflicts, scoped notes, безопасные tool results, лимиты каталогов и отсутствие прав от JSON-импорта. Интерфейсные проверки дополнительно проходят все 7 разделов на 11 языках.

Браузерные скрипты создают временную копию расширения с заранее выданными test host permissions. Нативный пользовательский диалог разрешений ими не проверяется. Исследуемый оригинал в этих сценариях не исполняется.

Не подтверждены живой DOM аккаунта, post-login ответы оригинального сервера и доступ конкретного аккаунта через настоящий OAuth. Эти статусы не заменяются fixtures или успешной локальной генерацией.
